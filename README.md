## 常见问题 FAQ

**Q：AT&T 和 Frontier 两个静态家宽有什么区别，选哪个？**

AT&T 是美国最大的电信运营商之一，IP 在各平台的住宅属性识别更广为人知；Frontier 是双 ISP 属性（部分 IP 段被数据库标注为双 ISP），在某些平台的兼容性上略有差异。两者带宽和流量配置完全相同，实际使用中区别不大，哪个有货买哪个就行。

**Q：静态家宽售罄了，怎么办？**

最直接的方式是联系客服预约下一批，提前付款的大额长周期订单可以享受优先交付权。也可以先买 NAT 动态套餐过渡，等到静态套餐有货再升级。

**Q：日本 SoftBank NAT 和 Frontier NAT 怎么选？**

SoftBank 是日本最大的移动运营商，日本 IP 环境下对 LINE、Yahoo Japan 等本土平台的识别更友好，但带宽只有 50Mbps；Frontier NAT 是美国 IP，带宽 100Mbps，适合需要美国 IP 低成本方案的用户。

**Q：购买前需要实名认证吗？**

静态家宽系列无需实名认证；动态 NAT 系列需要实名（绑定手机号）。官方的解释是实名机制是保护 IP 不被滥用的手段，能让 IP 质量维持更久——长期来看对用户也有好处。
